# Հարսանյաց հրավիրատոմս (անվճար)

Այս պրոյեկտը մեկ էջանոց հրավիրատոմս է (HTML/CSS/JS), որը հնարավոր է հրապարակել
**անվճար**՝ GitHub Pages-ի միջոցով, և ստանալ հասանելի հղում, որը կարող եք
ուղարկել հյուրերին։

## Ինչպես տեղադրել անվճար (GitHub Pages)

1. Բացեք repository-ի **Settings → Pages**։
2. **Source** դաշտում ընտրեք branch-ը (օրինակ՝ `main`) և `/ (root)` պանակը։
3. Սեղմեք **Save**։ Մի քանի րոպե անց հասանելի կլինի հղում՝
   `https://<ձեր-github-username>.github.io/<repo-անուն>/`
4. Այդ հղումը կիսեք հյուրերի հետ (WhatsApp, Viber, Telegram, Instagram story և այլն)։

> Alternatively, կարող եք անվճար տեղադրել [Netlify](https://netlify.com) կամ
> [Vercel](https://vercel.com)-ի վրա՝ պարզապես repository-ն կապելով իրենց հետ
> (drag-and-drop deploy-ն էլ է հասանելի)։ Երկուսն էլ ամբողջովին անվճար են
> այս տեսակի կայքի համար։

## Նկարներ (գալերիա)

Գալերիայի բաժինը ինքնաշխատ բեռնում է նկարներ `assets/gallery/` պանակից՝
1.jpg, 2.jpg, 3.jpg... (մինչև 24 հատ)։ Բավական է այնտեղ դնել ֆայլերը այդ
անուններով (կամ ասել՝ ես կփոխեմ անունները), մնացածն ինքն է աշխատում,
ոչինչ խմբագրելու կարիք չկա։

## Երաժշտություն

Կայքի ներքևի աջ անկյունում 🎵 կոճակով նվագարկվում է ֆոնային երաժշտություն
(`assets/music.mp3`)։ Բրաուզերները արգելում են ձայնով ավտոմատ նվագարկումը,
դրա համար հյուրը պետք է մեկ անգամ սեղմի կոճակին։ Երբ ուղարկես երգը (կամ
հղումը), ես կավելացնեմ `assets/music.mp3` ֆայլը։ Անվճար, առանց հեղինակային
իրավունքի խնդրի աղբյուրներ՝ [Pixabay Music](https://pixabay.com/music/),
[Chosic](https://www.chosic.com/free-music/all/), YouTube Audio Library։

## RSVP (հաստատումներ)

Ներկայումս RSVP ձևը backend չունի (քանի որ կայքն ամբողջովին ստատիկ և անվճար է)՝
հաստատումն ուղարկվում է որպես էլ. նամակ (`mailto:`)։ Եթե ցանկանում եք ավելի
հարմար տարբերակ (օրինակ՝ պատասխանները հավաքվեն աղյուսակում), կարող եք անվճար
օգտագործել [Google Forms](https://forms.google.com) և ներմուծել հղումը կայքում,
կամ [Formspree](https://formspree.io) (անվճար մինչև 50 ուղարկում/ամիս)։

## Լոկալ դիտում

Պարզապես բացեք `index.html` ֆայլը բրաուզերում, կամ գործարկեք տեղական սերվեր՝

```bash
python3 -m http.server 8000
```

և բացեք `http://localhost:8000`։
