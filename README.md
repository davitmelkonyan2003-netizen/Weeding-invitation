# Հարսանյաց հրավիրատոմս (անվճար)

Այս պրոյեկտը մեկ էջանոց հրավիրատոմս է (HTML/CSS/JS), որը հնարավոր է հրապարակել
**անվճար**՝ GitHub Pages-ի միջոցով, և ստանալ հասանելի հղում, որը կարող եք
ուղարկել հյուրերին։

## Ինչպես տեղադրել անվճար (GitHub Pages)

1. Բացեք repository-ի **Settings → Pages**։
2. **Build and deployment → Source**-ում ընտրեք **"Deploy from a branch"**։
3. **Branch** դաշտում ընտրեք `claude/free-wedding-invitation-b5ugqg`, կողքինում՝ `/ (root)` → սեղմեք **Save**։
4. Սպասեք 1-2 րոպե, թարմացրեք էջը. վերևում կերևա հղում՝
   `https://<ձեր-github-username>.github.io/<repo-անուն>/`
5. Այդ հղումը կիսեք հյուրերի հետ (WhatsApp, Viber, Telegram, Instagram story և այլն)։

> Եթե հղումը 404 է տալիս՝ նշանակում է Pages-ը դեռ չի պահպանվել (Save-ը չի
> սեղմվել, կամ branch/root ընտրված չէ)։ Վերադարձեք Settings → Pages և
> համոզվեք որ "Your site is live at ..." հաղորդագրությունը երևում է։

> Alternatively, կարող եք անվճար տեղադրել [Netlify](https://netlify.com) կամ
> [Vercel](https://vercel.com)-ի վրա՝ պարզապես repository-ն կապելով իրենց հետ
> (drag-and-drop deploy-ն էլ է հասանելի)։ Երկուսն էլ ամբողջովին անվճար են
> այս տեսակի կայքի համար։

## Նկարներ (ֆոն)

Բոլոր նկարները դրված են `assets/photos/` պանակում (1.jpg, 2.jpg...)։ Ներկայումս
օգտագործվում են 2.jpg (hero), 3.jpg (օրվա ծրագիր) և 4.jpg (footer)՝ որպես ամբողջ
էկրանի ֆոն։ 1.jpg և 5.jpg արդեն վերբեռնված են, պահուստում են, եթե ուզես ավելացնել
նոր բաժին։ Նոր նկար ուղարկես՝ դնում ենք `assets/photos/6.jpg`, `7.jpg`... և
ասում թե որ բաժնում օգտագործել։

## Բացվող կնիք (intro)

Էջը բացվելիս հայտնվում է էլեգանտ մոմի կնիք (wax seal)՝ սրտիկով և դափնու
թերթիկներով, առանց տառերի։ Հպելիս երկու կողմերը սահում են իրարից հեռու,
երևում է հրավերը, և միևնույն պահին ավտոմատ սկսվում է երաժշտությունը։

## Երաժշտություն

Ֆոնային երաժշտությունը քո ուղարկած YouTube տեսանյութն է, ներդրված որպես
անտեսանելի YouTube նվագարկիչ (100% օրինական, առանց ներբեռնման/հեղինակային
իրավունքի խնդրի)։ Կնիքին հպվելիս ավտոմատ սկսվում է, իսկ ներքևի աջ անկյան 🎵
կոճակով կարելի է դադարեցնել/միացնել (եթե բրաուզերն արգելափակի ավտոմատ
նվագարկումը, հյուրը կարող է պարզապես սեղմել այդ կոճակին)։

## Dress code գույները

`.dc-palette`-ի գույները վերցված են ձեր ուղարկած պաստելագույն ցանկից
(18 երանգ)։ Փոփոխելու համար խմբագրիր `index.html`-ի dresscode բաժինը։

## Լոկալ դիտում

Պարզապես բացեք `index.html` ֆայլը բրաուզերում, կամ գործարկեք տեղական սերվեր՝

```bash
python3 -m http.server 8000
```

և բացեք `http://localhost:8000`։
